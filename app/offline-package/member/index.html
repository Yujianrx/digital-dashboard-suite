METRIC DEFINITIONS

指标与比较口径

V11 使用主机共享数据库。小程序沿用原字段与历史记录，其他四个平台首次启用为零数据；无日期记录不代表当天已录入。

默认完成日与活动日历

默认截止日为昨天，初次打开及恢复默认按昨天所在自然月统计。日、周、月默认不含今天；本周、本月尚无完整日时快捷项禁用。手动选择今天或明确自定义到今天可查看当天数据。万年历提供农历、节日和二十四节气，日期列与活动排期同步标注；节日不代表放假或调休安排。

独立门店排行

在核心业绩下独立导入门店小程序实收及储值实收，按所选本期区间分别取前20名。对比使用上方所选区间，缺录不当作0。门店明细独立保存，不改写原两个业绩看板。模板支持空白保留、0写入、退款负数，整份校验后预览确认；编号相同的门店可改名，门店和日期重复时请先合并。

活动计划

活动计划按独立月份查看排期，起止日期包含当天。每场计划可选关联一个或多个小程序活动；效果逐个查看，范围为计划日期与所选月份的交集。漏斗可选择当前活动的数量字段，按原单位显示，不计算未经验证的转化率，也不跨活动累加人数。计划与平台数据分别保存。

导入与命名

两个核心模块可独立改名、下载模板并导入每日数据。导入值优先，缺项继续使用关联活动。各子平台下方的批量导入按活动编号或名称与日期更新，空白不覆盖、0 会写入；整份校验通过后预览并确认。

客单价

小程序客单价 = 实收 ÷ 有效订单数；储值客单价 = 储值实收 ÷ 储值订单数。按当前所选日期汇总金额和订单后相除，不平均每日客单价，不使用消费会员人次或商品份数。仅使用同日金额与订单数均有效的日期，并显示数据齐全天数；空缺不补零，订单数为0显示“—”，零金额且订单数大于0显示0.00。客单价为自动计算列，不导入也不改写历史数据；变更关联来源后，未确认的订单口径保持未配置。

两个主模块

小程序业绩关联原“小程序营业数据”，展示实收、销量与营业额。会员业绩关联原“会员储值”，储值实收单列，不计入消费。数据来源可在小程序字段设置中调整。会员消费、消费会员人次及新增会员可通过核心模块模板导入；人次按每日值相加，不代表期间去重人数。

日期快捷选择与自选对比

今天、昨天按单日统计；前7天、前30天按截至昨天的完整区间统计。本周、本月默认统计至昨天，也可选择自定义开始和结束日期。对比可选上月同期、紧邻本期之前的同等天数，或自行指定开始和结束日期；有效日期选择后自动应用。指标卡、五平台汇总、活动表现、趋势和对比导出均使用实际选定区间。自选区间天数不同仍按各自范围汇总，趋势按第1天起对齐；单次范围最长366天。日期筛选仅改变查看范围，不清空数据。

日 / 周 / 月与上月同期

日：选择日期的当天，对比上月同一日；上月无对应日期则不计算增幅。周：周一至周日，未结束周截至数据日期；对比区间从本期起始日向前移一个月，保持同等天数。月：自然月，未结束月截至数据日期；对比上月相同日序，遇短月截至月末。页面始终列出实际对比日期和天数。

主模块增幅 =（本期累计 ÷ 同期累计 − 1）× 100%。同期为 0 且本期大于 0 显示“无比较基数”；同期缺录显示“暂无同期”，不以 0 代替缺失。

活动类型与指标

每个平台均有业绩活动、转化率活动两类。可分别配置录入字段、指标卡与主指标；活动切换类型后隐藏的字段保留原始值。转化率活动默认展示券领取、券核销、券消费金额和参与人数。类型汇总逐项相加，排除已关联的平台总量记录；可能重叠的活动不能当作平台全量或去重人数。日均、百分比与期末值只在单个活动查看，不跨活动合计。

平台独立字段与汇总

五个平台分别配置指标名称、类型、单位、汇总方式、主指标和看板卡片。主指标用于跨平台总览及活动比较。期间合计包含有效零值；已录入日均以对应指标已录入天数为分母；期末值取期间最后一个已录入值。空白不视作 0。

百分比按 0–100 录入，期间日均是算术平均，不是加权转化率；同期变化显示百分点。访问人数、到店参与人数等可累计字段使用“人次”，不代表跨日去重人数。

平台全量数据与单个活动数据分别维护，不重复相加。停用字段仅隐藏，不删除历史值；恢复后重新显示。字段改名、排序不改变历史数据。五个平台设置相互独立。

本版本替换旧版统一的活动日均口径，全部平台指标按各自配置汇总。V10 小程序字段原样启用，历史活动、待办、品牌信息保留在原数据库记录中。新平台初始不带任何演示活动。
