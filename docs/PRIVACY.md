# 隐私和发布范围

本仓库采用空数据发布，不通过改名保留原业务记录。

- 不包含数据库、备份、导入文件、缓存、日志、个人账户文件或生产连接配置。
- 已去除网页内嵌的门店和负责人资料、原业务汇总值及压缩业务数据。
- 已移除品牌名称、品牌图片、私有来源编号、原活动/商品/券编号集合和内部访问地址。
- 页面以空数据启动。测试数据均由测试代码人工构造，与生产记录无关。
- 地图是公开行政区划地理资源，不包含企业门店点位；来源见大屏地图文档。
- 私有数据目录、环境文件及本地构建被 `.gitignore` 排除。`npm run check:public` 检查待发布源文件和空模板。

初次安装仅初始化空数据库。之后启动不会用模板覆盖已有数据。不要把导入后的数据库、日志、包含真实业务信息的截图或备份重新提交到公开仓库。

`docs/screenshots/` 中的介绍图片来自独立临时环境，所有数值与活动均为人工构造，图内标注“虚构演示数据”。这些图片仅用于说明界面与功能，不包含真实门店、人员或业务记录，也不会作为首次启动数据导入。详见 [截图说明](screenshots/README.md)。

此版本没有修改现用看板、历史数值或定时同步任务。数据来源与认证信息需要部署者在自己的环境中单独配置。

网站管理员凭据仅从部署环境读取，不写入静态资源。静态包仅包含前端与空模板，浏览器导入数据不会上传到 GitHub Pages。服务器和静态模式使用明确配置，接口失败不会改变保存位置。
