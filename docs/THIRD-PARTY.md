# 第三方组件与来源

- 会员运营和活动数据的 SheetJS、Chart.js、lunar-javascript 保留在各自 `vendor/` 目录，随附原始许可与来源文件。
- 经营大屏沿用已有通用大屏项目，保留 `operations/LICENSE`、`operations/third_party/` 和地图资源说明。Vue、ECharts、Three.js 等依赖由锁定文件记录，安装后可查对应包许可。
- 营业统计保留原安装版单文件构建，包含 React 等前端运行时及其随包声明；未包含原有业务样本数据。
- 本套件的新整合代码未额外指定统一开源许可证；各第三方组件继续按其原许可使用，公开托管不变更许可。
