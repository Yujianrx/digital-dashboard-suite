# 项目介绍截图

本目录图片均为项目实际页面截图，用于介绍多平台会员运营数据看板。

| 图片 | 展示内容 |
| --- | --- |
| `platform-workspace.png` | 小程序、视频号、小红书、抖音视频和公众号统一工作台 |
| `operations-overview.png` | 小程序业绩、会员储值、趋势与五平台指标对照 |
| `platform-detail.png` | 小红书独立指标、每日趋势、活动表现及导入入口 |
| `campaign-planning.png` | 小程序活动月度甘特排期、执行阶段与储值效果 |

## 数据来源

- 所有金额、数量、活动名称和排期均为人工构造，与任何真实业务记录无关。
- 数据仅写入截图专用的临时数据库；未读取生产数据库、备份或外部平台数据。
- 展示日期固定为 2026 年 10 月 18 日，每日统计示例覆盖 10 月 1—17 日，对照期为 9 月 1—17 日。这些日期仅用于展示日期筛选和同期对照。
- 每张图片右上角均有“虚构演示数据 · 仅供界面展示”标识，活动名称也注明“虚构”。截图使用项目自身组件渲染，标识仅在截图浏览器中添加。
- 不含真实品牌图片、门店、人员、账户、访问凭据或生产连接配置。

首次启动仍使用 `server/initial-state.json` 中的空模板。截图不是预装演示数据，也不代表平台接口已接通。平台报表由使用者自行导入或录入；活动计划效果目前关联小程序活动。
